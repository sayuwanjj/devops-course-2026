# Мои цели на семестр

1. Научиться уверенно работать с Git в терминале: ветки, Pull Request, rebase и разрешение конфликтов.
2. Упаковать учебный Python-проект в Docker-образ и запускать его через Docker Compose.
3. Настроить в GitHub Actions автоматическую проверку (линтер и тесты) для каждого Pull Request.
