# Мой пет-проект

Идея: Telegram-бот «Учёт расходов студента» — записывает траты по категориям
(еда, транспорт, учёба) и присылает отчёт за неделю и месяц с графиками.

Стек: Python 3, aiogram, SQLite, pandas + matplotlib для отчётов, Docker.

Цель: научиться доводить проект до «продакшена» — тесты на pytest,
контейнеризация в Docker и автоматическая проверка через GitHub Actions.

## Сроки реализации
- Октябрь: MVP — добавление трат и просмотр списка.
- Ноябрь: отчёты с графиками, тесты.
- Декабрь: Docker-образ и CI в GitHub Actions.
