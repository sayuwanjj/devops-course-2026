# Git в VS Code и в терминале

## Что удобно делать в VS Code
1. Смотреть diff: изменённые строки подсвечены рядом со старой версией, сразу видно, что поменялось.
2. Индексировать и коммитить отдельные файлы кнопками «+» и «✓» в панели Source Control без набора команд.
3. GitLens показывает прямо в строке кода, кто и когда её изменил (git blame), и историю файла.

## Что удобнее в терминале
1. Interactive rebase, cherry-pick и reflog: в терминале видны все параметры и полный вывод,
   команды можно повторить и вставить в скрипт, а на сервере по SSH IDE вообще нет.
